# Save eaten amounts, not plated portions, in reusable meals

Status: accepted.

Diary entries preserve both the original food quantity and the percentage eaten. Saved meals store the resulting eaten quantity and a reusable food profile, so repeating a 70%-eaten dinner logs the same nutrition rather than a fresh full plate. This keeps historical diary records stable even if the original food changes; reusing a template makes a new dated entry, never mutates the prior one. The trade-off is that reusable snapshots can become outdated and must be editable or deletable.
